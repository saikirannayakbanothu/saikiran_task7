Responsive laundry services webpage created using HTML and CSS.

## Features
- Responsive navigation bar
- Logo and username
- Navigation links
- Laundry services hero section
- Heading and description
- Book a Service Today button
- Laundry-related image
- Desktop, tablet, and mobile layouts
- Media queries for responsiveness
- Flexbox for layout

## Technologies Used
- HTML5
- CSS3
- Flexbox
- Media Queries

## How to Run
1. Download or extract the project folder.
2. Make sure `index.html` and `index.css` are in the same folder.
3. Open `index.html` in a web browser.
4. Resize the browser to test desktop, tablet, and mobile views.
